## 原則

1. DBは触らない。`src/data/grants/verified-*.ts` を追加し、`src/lib/grants.ts` の先頭側で同一slugを先勝ちdedupeする。
2. 公式ページで制度名・対象・金額・期限を確認できないものは、通常一覧に残さない。
3. 期限切れは `deadlineDate` を明示し、`npm run audit:deadlines` の詳細HTMLチェック対象にする。
4. 公式確認不可は「公式助成確認不可」と明示し、掲載停止日を期限切れ判定に使う。
5. 古い生成データは削除しない。削除ではなく公式確認済みデータで置換する。

## 検証コマンド

毎バッチで必須:

```bash
npx eslint <追加ファイル> src/lib/grants.ts
npm run lint
npm run build
npm run audit:coverage
npm run audit:deadlines
npm run audit:links
```

加えて、生成HTMLと本番HTMLで以下を確認する。

- 通常公開: 公式出典確認済み、確認日、公式情報リンク、sitemap掲載、noindexなし
- 期限切れ/公式確認不可: 「これは期限が切れています」、noindex, follow、sitemap除外

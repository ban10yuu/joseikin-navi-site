# 視覚イラスト改善 ベースライン

確認日: 2026-07-14
対象: https://shienseido-navi.jp/

## 1440px相当

- H1、説明、検索フォームの順序は明快。
- ファーストビューは文字と白い検索パネルが大半を占め、用途を直感で伝える視覚要素がない。
- 既存画像は8点だが、表示されるのは下層のカテゴリ画像が中心。
- `scrollWidth` と `clientWidth` はともに1425pxで横スクロールなし。

## 390px相当

- 見出しと検索フォームだけでヒーローが約1018pxになり、淡白な印象が強い。
- 検索操作は崩れていないが、目的ボタンは横スクロールで一部が画面外になる。
- `scrollWidth` と `clientWidth` はともに375pxでページ全体の横スクロールなし。

## 改善の焦点

- ヒーローに検索用途を示す人物入りイラストを追加する。
- 個人／事業者の入口は、人物と具体物で違いを即座に伝える。
- カテゴリ画像を同一タッチのモチーフへ統一する。
- 申請前ガイド、情報確認方法、0件状態だけを補助的に視覚化する。
- 制度カードや公式CTAには装飾を増やさない。

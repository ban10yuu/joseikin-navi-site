# 助成金ナビ 全自治体・公的機関 公式棚卸し運用ルール

このファイルは、既存rawデータの公式確認ではなく、国・都道府県・市区町村・公的機関の補助金、助成金、給付金、一時金を公式サイトから網羅的に棚卸しするための運用ルールです。

## 重要な前提

- `tasks/progress-checklist.md` の `raw gap 0` は、既存rawデータに対する公式確認が完了したという意味に限る。
- `raw gap 0` を、全国の全自治体・全公的機関の制度を網羅した意味で使ってはいけない。
- 全国完了と言える条件は、このファイルの「完了条件」を満たした場合だけ。

## 対象範囲

1. 国の制度
   - 省庁、外局、独立行政法人、公的基金、全国実施の公的給付・補助制度。
2. 都道府県
   - 47都道府県の公式サイト、外郭の公式補助金ポータル、公式PDF。
3. 市区町村
   - 全国の市、特別区、町、村。
   - 政令指定都市の行政区は、区独自制度がある場合のみ個別に扱う。
4. 公的機関
   - 商工会議所、社会福祉協議会、公社、財団、信用保証協会等は、公的資金または自治体連携制度として公式確認できるものを対象にする。

## 制度として収録するもの

- 補助金
- 助成金
- 給付金
- 支援金
- 一時金
- 奨励金
- 償還払いを含む費用助成
- 現物給付・利用券・ポイント支給
- 減免、免除、利子補給、保証料補助

## 完了条件

自治体または公的機関ごとに、以下を満たすまで完了扱いにしない。

1. 公式サイト内検索、サイトマップ、カテゴリページ、PDF、更新情報を確認する。
2. 次のキーワードを組み合わせて検索する。
   - `補助金`, `助成金`, `給付金`, `支援金`, `一時金`, `奨励金`, `減免`, `免除`, `償還払い`, `利子補給`, `保証料`, `補助`, `助成`
3. 公式ページまたは公式PDFで制度名、対象者、金額・助成内容、申請期間、担当部署を確認する。
4. 収録する制度は `officialUrl` と `sourceUrls` を持つ。
5. 公式確認できない制度は「掲載停止」または収録対象外として、理由を記録する。
6. 対象自治体の棚卸し結果をチェックリストに残す。
7. `npx eslint`、URL到達確認、`npm run audit:coverage`、`npx next build --webpack` または節目buildを通す。

## 進め方

1. まず自治体マスターを作る。
   - 総務省所管の全国地方公共団体コード、J-LIS地方公共団体コード住所、e-Stat市区町村コード等を照合元にする。
2. 既存サイト内の収録自治体と突き合わせる。
3. 未棚卸し自治体を `tasks/comprehensive-official-coverage-checklist.md` に並べる。
4. 1自治体ずつ、公式検索と制度追加を行う。
5. 自治体単位でコミットする。
6. 県単位、100自治体単位、全国完了時にbuildと本番確認を行う。

## ユーザーへの報告ルール

- 「全国完了」「全件完了」と言ってよいのは、この棚卸しチェックリストが0件になった時だけ。
- 既存rawデータの確認完了は「既存rawデータの公式確認完了」と表現する。
- 天理市のように公式検索で追加制度が見つかった場合は、サイト表示件数を完了件数として断定しない。

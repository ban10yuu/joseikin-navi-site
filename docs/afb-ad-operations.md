提携済みの全案件は `data/afb-partnered-programs.json` で管理する。

## 公開までの流れ

1. `data/afb-partnered-programs.json` で提携済みであることを確認する
2. afb管理画面で、支援制度ナビ向けの広告原稿を取得する
3. ASP発行HTMLを変更せず `src/config/affiliate-issued-html.ts` に保存する
4. `src/config/affiliate-offers.ts` に対象者、目的、利用場面、掲載可能ページを設定する
5. 画像、計測タグ、最終遷移先、訴求内容を監査する
6. テストと `npm run audit:affiliates` を通過した案件だけ公開する

提携済みという理由だけで全ページに同じ広告を出さない。制度ページでは対象者、主目的、本文から得た利用場面が一致する案件を優先し、医療・福祉・災害・生活困窮などのページは別の明示承認がない限り表示対象にしない。

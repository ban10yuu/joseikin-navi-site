# アフィリエイト案件の有効化手順

最終更新日: 2026-07-19

## 現在の状態

- A8.netアカウントへのログインを確認済みです。
- `https://shienseido-navi.jp/`を「支援制度ナビ」としてA8.netの副サイトへ登録済みです。
- 設定済み22案件のうち、提携・素材・確認期限・文脈条件を満たす16案件を公開対象にしています。
- KANBEI SIGNは素材内の制度横断表現を確認できないため停止中です。幅300pxを超える再エネ相談とRemofulも、320px画面で未改変のまま表示できる公式素材を取得するまで停止しています。
- スマレジ・タイムカードは提携審査中です。`enabled=false`、`destinationUrl=null`のため公開画面へ表示されません。
- もしもアフィリエイトへ「支援制度ナビ」をメディア登録済みです。
- 提携審査中、素材未確認、確認期限切れの案件は`enabled=false`として公開を停止します。

## 有効化前に必要なASP側の作業

1. 候補案件の詳細画面で禁止事項、掲載条件、成果条件、提携審査の有無を確認します。
2. 広告掲載予定のサイトとして「支援制度ナビ」を選んで提携申請します。
3. 提携承認後、ASPが発行するバナーHTMLを一切変更せず取得します。
4. コード側の公開条件を更新し、全監査が通った場合だけ有効化します。

パスワード、メディアID、広告リンク、トラッキングIDをこの文書や作業報告へ貼り付けないでください。広告リンクは公開に必要な設定ファイルだけで管理します。

## コード側の有効化

対象案件について次を更新します。

- `network`: `A8.net`または`もしもアフィリエイト`
- `destinationUrl`: ASPが発行したHTTPSの広告リンク
- `partnershipStatus`: `partnered`
- `enabled`: `true`
- `verifiedAt`: 条件とリンクを再確認した日
- `validFrom` / `validUntil`: ASP上で掲載期間を確認できる場合のみ設定
- `trackingId`: 必要な場合だけ設定し、画面へ表示しない
- `src/config/affiliate-issued-html.ts`: ASP発行HTMLを未改変で保存

更新後、次を実行します。

```bash
npm run audit:affiliates
npm run lint
npm run typecheck
npm test
npm run build
npm run test:e2e
npm run audit:build
```

重大エラーが1件でもある場合は公開しません。

## 表示ルール

- トップの初期表示は選択中の個人・家族向け案件を3件、事業者・団体向けへ切り替えた場合は4件表示します。制度詳細は文脈に一致する案件を最大3件まで、公式情報の後に分けて表示します。
- トップと事業者向けガイドはaudience、purpose、intentが一致する案件だけを表示します。
- 制度詳細では公式情報の後にだけ表示し、デスクトップは右レール、モバイルは本文幅で表示します。
- 制度名・概要だけでなく対象条件も判定に使い、団体・雇用主向け制度へ個人向け広告を出しません。受付終了制度は文脈一致時のみ表示し、noindex・修正待ち・一時停止は非表示です。
- 公式CTAとPR枠は色、位置、文言を分け、医療、福祉、災害、生活支援、障害対象のページでも制度の申請に必須ではない広告だと判別できる表示を維持します。
- ボタンに「申請する」「受給」など、制度手続きと誤認する文言を使いません。
- PR表記と自社説明はASP発行タグの外側に置きます。発行タグ内の`rel`、画像、計測pixel、属性は変更しません。

## 定期確認

公開案件は少なくとも月1回、ASP上の提携状態、終了予定、広告リンク、広告主の条件変更を確認します。終了・停止・リンク不明を確認した時点で、先に`enabled=false`へ戻してから調査します。
定期監査は広告素材の取得だけを任意実行し、成果計測URLにはアクセスしません。遷移先はASP管理画面で確認したhostと確認日を記録します。

## もしもアフィリエイトで案件を追加する場合

もしもアフィリエイトでは、広告主名、案件名、提携状態、成果条件、掲載禁止事項、広告リンクを確認してから`src/config/affiliate-offers.ts`へ追加します。申請中案件は`partnershipStatus='applied'`として管理し、公開しません。

登録だけでは公開画面に「もしもアフィリエイト」を表示しません。`enabled=true`、`partnershipStatus='partnered'`、HTTPSの`destinationUrl`、`verifiedAt`が揃った案件が1件以上ある場合だけ、プライバシーポリシー上の利用中ASPへ自動反映されます。

承認後は、もしも側で発行された広告HTMLと公式バナーをそのまま取得し、案件ごとに掲載条件、対象者、目的、intentを再確認してから有効化します。

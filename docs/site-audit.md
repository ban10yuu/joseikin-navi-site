# サイト監査レポート

確認日：2026年7月13日
対象：助成金ナビの公開画面、制度データ、ビルド成果物

## 確認した問題

- 掲載件数を複数箇所へ直接記載していたため、トップ、一覧、カテゴリで数字がずれていました。
- 受付終了後も「締切間近」や申請を促す文言が残る可能性がありました。
- 詳細ページに制度種別、対象者、目的、確認方法を共通形式で持つ仕組みがありませんでした。
- 自動照合と人手確認の表示を区別できず、内部監査用の文章が本文に混ざっていました。
- 一覧とカテゴリで全制度データをブラウザへ送り、端末側で絞り込んでいました。
- ヘッダー、フッター、制度詳細、広告枠に新旧の部品が混在していました。
- 広告や外部サービスの記載が、実際の設定状況と連動していませんでした。
- 制度内容が変わった2ページでURL名と本文が一致していませんでした。
- 古い診断クイズと必要書類案内のコードが残っていました。
- 検索条件ページや確認不足ページを検索エンジンから除外する基準が不足していました。

## 原因

制度データが長期間にわたり複数形式で追加され、表示側が個別の文字列や件数を持っていました。受付状況、公式確認、検索公開、収益化を同じデータから判定する層もありませんでした。さらに、古い静的出力を前提にした監査と、新しいNext.jsの構成が混在していました。

## 修正内容

- 既存データを壊さず、公開時に共通形式へ変換する正規化層を追加しました。
- 件数、受付状況、貸付表示、公式情報の有無、noindexを共通関数で判定します。
- `automated`、`human`、`mixed`、`unknown`を分離し、人手確認日は明示データがある場合だけ表示します。
- 一覧をサーバー側検索、24件単位のページネーション、URLクエリ方式へ変更しました。
- トップ、カテゴリ、地域、詳細を共通のヘッダー、フッター、カード、公式CTAへ統一しました。
- 公式CTAをPRより先に置き、案件未設定時は広告ラベルと余白を含めて表示しません。
- プライバシーポリシーは、環境変数で有効になったサービスだけを表示します。
- 終了制度のCTAを「次回募集・後継制度を公式サイトで確認」へ統一しました。
- 旧URL2件に301リダイレクトを設定しました。
- 検索条件付き一覧は `noindex,follow`、確認不足や修正待ちはnoindex、サイトマップはindex可能な制度だけにしました。
- 制度データ監査とビルドHTML監査を追加しました。

## 実測

- 制度データ監査：重大エラー0件、警告2,201件
- ビルドHTML監査：7,322ページ、重大エラー0件、警告75件
- E2E：33ケース、失敗0件
- axe：6ページでcritical/seriousの違反0件
- Lighthouse中央値：Performance 97、Accessibility 100、Best Practices 100、SEO 100
- 本番ビルド：成功、静的生成7,323ページ

## 今回修正しなかった項目

- 説明文不足1,197件、公式URL重複665件、タイトル重複202件など、公式資料を再確認しないと直せないデータは自動補完していません。
- 人手確認済みの制度は0件です。確認していない制度へ人手確認ラベルは付けていません。
- 実案件とASP URLがないため、アフィリエイト表示は無効のままです。
- メール配信先がないため、登録フォームは公開しません。
- INPは実利用時の操作データが必要なため、ローカル計測だけでは確定していません。

## 運営者の確認が必要な項目

- 運営者名、問い合わせ用メールまたは問い合わせフォームURL
- 独自ドメインの本番URL
- 利用するアクセス解析、広告、メール配信サービスと保存期間
- Search Consoleの所有権確認値
- アフィリエイト案件の広告主、リンク、掲載期間、確認日、表示文言
- noindex中の2,518件を再公開する場合の公式資料確認

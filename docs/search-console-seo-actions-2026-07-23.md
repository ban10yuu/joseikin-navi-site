# Search Console起点のSEO改善ログ（2026-07-23）

## 確認した流入状況

- GA4リアルタイムでは、過去30分でアクティブユーザー2〜3人を確認。
- 流入元はGoogle検索。
- 表示ページはトップ、子育てカテゴリ、自治体制度詳細ページが中心。
- Search Consoleでは、自治体名＋制度名のクエリがすでに表示・クリックを獲得している。

## 実装した改善

- トップページに「検索されている制度を直接確認する」導線を追加。
- Search Consoleで見えている具体クエリを、確認済みの制度詳細ページまたは関連カテゴリへ内部リンク化。
- 詳細ページのmeta descriptionを、検索結果で伝わりやすい順序へ修正。
  - 制度名
  - 実施機関
  - 対象者
  - 支援額
  - 申請期間
  - 公式情報確認
- 「人気」など実測順位を誤認させる表現は使わず、制度名・自治体名から探す導線として表示。

# イラスト生成プロンプトと採用記録

## 生成方式

- built-in image generationを使用。
- 人物は3列×2行、モチーフは6列×4行のシートで生成。
- 原版を残し、等分したセルをWeb向けWebPへ変換する。

## 共通アート指定

- 日本の公的支援情報サイト向けの、落ち着いた編集型フラットイラスト。
- 濃紺 `#17345F`、青 `#2557A7`、緑 `#25846B`、琥珀 `#D58A2A`、珊瑚 `#DF806F`。
- 均一な輪郭、丸い線端、同一の余白率、白から淡い青灰色の背景。
- 文字、数字、通貨記号、ロゴ、行政紋章、透かしを描かない。
- グラデーション、光沢、3D、写実、強い影、質感、過剰な装飾を使わない。

## 人物シート

1. 公式書類、地図ピン、虫眼鏡を囲んで制度を探す複数世代の利用者。
2. 家、通学用品、医療モチーフと親子。
3. 店舗、ノートPC、書類、植物と事業者。
4. 3枚の申請書類を順番に整理する利用者。
5. 公式ページ、カレンダー、確認マークを照合する編集者。
6. 地図と地域ピンを見ながら制度を探す住民。

人物は点の目、短い口、ミトン状の手、簡略化した自然な姿勢とする。細かい指、誇張した顔、浮遊物、極端な頭身を避ける。

## モチーフシート

子育て、住宅、医療、教育、雇用、介護、生活支援、災害、創業、事業成長、デジタル化、省エネ、賃上げ、福祉、地域活性、研究、学生、障害者支援、貸付、給付、減免、利用券、申請書類、公式情報検索の24点。

すべてを同一サイズのセルへ中央配置し、48px表示でも識別できる単純な形にする。

## 採用判断

- モチーフ第1稿は塗りに光沢感が強いため不採用。
- モチーフ第2稿を採用。セル配置、輪郭、色の統一性が高く、文字混入なし。
- 人物第1稿を採用。6場面のタッチが揃い、手指が簡略化され、用途が判別できる。
